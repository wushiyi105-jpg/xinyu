# UI 说明：心语

- **谁在什么时刻打开**：给想回看压力场景的人。
- **首屏任务句**：今天，先记一句。
- **主操作**：按「只写一句 → 标签自己定 → 回看这一周」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：布面日记；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：布面日记。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给想回看压力场景的人：一句话就能保存，标签由你接受或改掉；周回顾只列实际出现的场景，导出由你选。
